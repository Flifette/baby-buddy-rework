# Contributing / Contribuer

Thank you for taking an interest in Baby Buddy Dashboard Rework. This is a personal project maintained in my spare time, so contributions that stay focused, documented, and easy to review are especially welcome.

Before opening a pull request:

- start from the `dev` branch and use a dedicated branch;
- keep each contribution limited to one clear subject;
- never include API keys, personal care data, backups, runtime files, or local configuration;
- explain what changes and why;
- run the relevant tests and frontend build when the add-on is affected;
- keep the existing French and English interface in sync.

For security problems, please use GitHub's private vulnerability reporting instead of a public issue.

Merci de vous intéresser à Baby Buddy Dashboard Rework. Ce projet personnel est maintenu sur mon temps libre : les contributions ciblées, documentées et simples à relire sont donc particulièrement appréciées.

Avant d’ouvrir une pull request :

- partez de la branche `dev` et utilisez une branche dédiée ;
- limitez chaque contribution à un sujet clair ;
- n’ajoutez jamais de clé API, donnée personnelle, sauvegarde, fichier runtime ou configuration locale ;
- expliquez ce qui change et pourquoi ;
- lancez les tests pertinents et la compilation du frontend lorsque l’add-on est concerné ;
- conservez la cohérence entre les interfaces française et anglaise.

Pour un problème de sécurité, utilisez le signalement privé de vulnérabilité GitHub plutôt qu’une issue publique.
